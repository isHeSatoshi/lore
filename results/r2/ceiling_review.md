# Manual ceiling review

Source: [`ceiling_review.json`](ceiling_review.json), generated by
`python -m lore.bench.review_baselines --run r2`.

I compared the raw cached model text with the extracted SQL and the supplied
gold SQL for every case below. All ten extractions preserve the model's SQL,
apart from removing Markdown fences and a terminal semicolon. Both queries
execute without errors in each case. Re-execution still disagrees under the
fixed set-of-tuples evaluator.

| Question | Observed SQL differences |
|---|---|
| t4 | Omits `rtype = 'S'` and the `cds` tie-break when selecting the seventh ranked result. |
| t3 | Restricts Orange County only in the numerator, not the denominator. |
| t1 | Uses `FundingType = 'Directly funded'` instead of `'Locally funded'`. |
| t5 | Uses free-or-reduced-price eligibility rather than the requested free-meal percentage, and does not convert the stated percentage threshold. |
| t20 | Constructs districts using `SOCType` and assumed district-only rows instead of the gold's `DOCType` scope. It also loses the association between an administrator and their school. |
| t52 | Does not replace line breaks with spaces, despite the explicit one-line output requirement. |
| t59 | Omits `translation IS NOT NULL` and counts a different set key. |
| t80 | Uses uppercase `'B'` rather than the explicitly requested lowercase `'b'`. |
| t95 | Uses uppercase `'Azorius'` instead of the stored lowercase `'azorius'`. |
| t106 | Uses a left join and sums all block sets rather than only joined translated sets; also adds nonempty-translation restrictions absent from the gold. |

These cases do not indicate an extraction or evaluator bug. Some questions
admit interpretation differences, but the benchmark's supplied gold and metric
remain unchanged. This is not a review of every wrong answer and is not a
ceiling-completion or accuracy-gate claim. No reviewed test question was used
for learning or to change the reflection prompt.
